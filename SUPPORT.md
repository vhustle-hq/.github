# Getting help

- **Bugs and feature requests:** [vhustle-hq/feedback](https://github.com/vhustle-hq/feedback/issues/new/choose), using one of the forms.
- **Security problems:** report privately, as described in [SECURITY.md](https://github.com/vhustle-hq/.github/blob/main/SECURITY.md).
- **Your account, subscription, privacy or data deletion:** never post these publicly. Use **You → Help** in the app.
