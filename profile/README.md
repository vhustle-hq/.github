# Vhustle

One coach for how you train, recover, sleep and eat. Type or say what you did, and your plan adapts every day.

Vhustle is in development for iPhone and Android. Our code is private. This organization hosts our public feedback tracker.

## Report a bug or request a feature

Open an issue in [**vhustle-hq/feedback**](https://github.com/vhustle-hq/feedback/issues/new/choose). Read [the rules](https://github.com/vhustle-hq/feedback#rules) first: reports that skip the form or break the rules are closed.

## Report a security problem

Never open a public issue for a security problem. Report it privately through [GitHub's private vulnerability reporting](https://github.com/vhustle-hq/feedback/security/advisories/new).
